2. DATA PERSISTENCE & FAULT-TOLERANT ARCHITECTURE
--------------------------------------------------------------------------------
* Dual-Mode Resilient Data Engine:
  - Primary Engine: Live MongoDB Atlas via Mongoose 9 ODM.
  - Failover Engine: In-memory resilient cache (`store.js`) mirroring all 18 Mongoose
    model operations (find, findOne, create, updateOne, deleteOne, populate, countDocuments).
  - Benefit: Guarantees zero system downtime during network disruptions, DNS anomalies,
    or missing cloud credentials.
* Automatic Database Initialization & Seeding:
  - On startup, `config/db.js` verifies the presence of the system administrator
    account (`admin@wecanchange.org`) and provisions it if absent.
  - DNS resolution overrides (`8.8.8.8`, `1.1.1.1`) applied to guarantee reliable
    SRV lookup when connecting to MongoDB Atlas clusters on Windows.
* Comprehensive Audit Trail:
  - Every mutating action (status change, wing request review, issue assignment,
    reimbursement approval, attendance mark, user creation) triggers an immutable
    entry in `AuditLog` containing: user ID, action, module, timestamp, and details.

3. AUTHENTICATION, ROLES & PERMISSION ARCHITECTURE
--------------------------------------------------------------------------------
* Authentication Mechanism:
  - Native JWT with HS256 algorithm and 7-day expiration.
  - Standardized Bearer token storage in browser `localStorage` (`wcc_token`).
  - Passwords securely hashed with bcryptjs (10 salt rounds).
  - Password recovery: Crypto-generated hex tokens with 1-hour expiration.
* Supported User Roles & Permissions:
  1. Admin:
     - Global system oversight across all wings, finances, programs, and members.
     - Role elevation, member approvals, issue assignment, project budgeting.
     - Access to master audit log (`/api/audit`).
  2. Coordinator:
     - Wing-scoped operations: Authorized to manage events, registrations, attendance,
       and community issues strictly within their assigned wing.
     - Prevented from modifying or viewing sensitive resources belonging to other wings.
  3. Finance Officer:
     - Financial transaction ledger, accounts management, advance settlements,
       and reimbursement approval workflows.
  4. Member:
     - Digital ID card generation with dynamic QR verification code.
     - Personal profile management, member directory discovery.
     - Wing transfer request and volunteer upgrade application submission.
     - Personal reimbursement claim submission and event registration.
  5. Volunteer:
     - Volunteer Corps dashboard, digital recognition credential badge.
     - Service hours logging with campaign/drive tracking.
     - Historical service log review and total volunteer hour counters.
     - Event registration and attendance tracking.
  6. Public Guest:
     - Browse public wings, programs, events, vision/mission, and submit community issues.
     - Verify member or volunteer credentials via QR scan on `/verify`.
